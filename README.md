# NYAANO Brand Website

Static, dependency-free website built for fast Vercel/Netlify/static hosting.

## Launch checklist
1. Replace every `nyaano.example` canonical/OG URL with the real domain.
2. Connect the retailer enquiry form to a real endpoint/CRM/WhatsApp workflow.
3. Replace pre-launch wording only after production, distribution and QC claims are verified.
4. Verify final MRP before publishing any price.
5. Confirm all label/regulatory language with Nepal food compliance requirements before using pack artwork commercially.
6. Add real store availability pages once distribution is confirmed.

## SEO/AEO/GEO included
- Semantic HTML and strong heading hierarchy
- Unique title/description per page
- Product + FAQ + Organization structured data
- robots.txt and sitemap.xml
- llms.txt for clear entity/context retrieval
- Direct answer blocks and FAQ language
- English + Nepali brand terminology
- Lightweight WebP assets and no framework dependency

## Hosting
Upload the folder to a static host, or create a Vercel project and deploy this directory.
